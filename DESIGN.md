# Design

The board is a shared wardrobe worktable: two labeled locations sit side by side, while the first viewport uses an occasion → garment group → clothing items overview to keep a large wardrobe easy to scan. A full list view keeps clothing cards tactile and sortable for editing work. It is an operate surface, so the object being managed remains close at hand without making every record compete for attention on initial load.

Use a restrained, cool daylight palette: ink navy for structure, chalk for the page, cobalt for actions and focus, and one warm saffron signal for unsaved work. The two locations are differentiated by small A/B index plates and restrained color fields, not competing themes. Keep borders crisp, radii modest, and shadows shallow enough that drag targets remain obvious.

The composition is a split worktable: a compact utility header, a full-width dirty/save rail, then two equal location columns. Each column starts with occasion tiles, drills into Tops / Bottoms / Accessories / Other, and then exposes grouped clothing cards. A List toggle returns to the complete sortable list. Cards use a compact summary row with the item name, quantity, and garment type, then reveal labelled metadata and editing controls on demand. Occasion overlaps, brand, and colour stay in the expanded detail area so multiple tags do not compete beside the item name. A dedicated grip keeps pointer, touch, and keyboard affordances legible.

Typography uses the system UI stack with compact uppercase metadata and firm, slightly tight headings. Motion is functional: cards lift on drag, columns highlight when they accept a drop, save status changes are immediate, and dialogs enter quickly without theatrical transitions.

Responsive behavior stacks the two locations at narrow widths while keeping the save action in the top utility rail. Search stays visible and secondary filters collapse into an expandable panel. Focus rings must remain visible, drag handles must have text alternatives, and destructive deletion must always ask for confirmation.
